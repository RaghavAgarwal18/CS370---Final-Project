# CS370---Final-Project

Run dashboard_server.py on the laptop, and run TrackerWStats.py on the Pi. Then set the tracker’s server URL to the laptop’s IP address, for example:

POSTURE_STATS_SERVER=http://192.168.1.50:5000

On the Computer, start the dashboard server normally:

python dashboard_server.py

Then open the dashboard in the laptop browser at:

http://localhost:5000
